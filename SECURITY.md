# Security Policy

## Supported Versions

Security fixes go into the latest 2.0.x release.

|  Version  | Supported          |
| --------- | ------------------ |
| 2.0.x     | :white_check_mark: |
| < 2.0.0   | :x:                |

## Reporting a Vulnerability

Please report it privately, not in a public issue:

- **Preferred:** use GitHub's
  [private reporting](https://github.com/caronc/dateblock/security/advisories/new)
  (the **Security** tab, then **Report a vulnerability**).
- **Or:** email lead2gold@gmail.com with "dateblock security" in the subject.

Include the dateblock version, how you use it (the command line tool, or the
Python, PHP or Node.js bindings), and the steps or input that trigger it.

What happens next:

- You'll get a reply within a week.
- Once it's confirmed, a fix is released and the problem is announced in a
  GitHub security advisory; you're credited there unless you'd rather not
  be.
